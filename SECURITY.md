# Kebijakan Keamanan

| Versi | Didukung |
|-------|----------|

## Melaporkan kerentanan

**Jangan** laporkan kerentanan keamanan lewat *issue* publik.

Gunakan salah satu jalur privat berikut:

1. **GitHub Private Vulnerability Reporting**: tab *Security* → *Report a vulnerability* di repositori ini.
2. Email ke **halo@setiadifoss.org** dengan subjek `[SECURITY] Rangkui`.

Sertakan versi Rangkui, langkah reproduksi, dampak yang diperkirakan, dan (bila ada) usulan perbaikan.

Kami berupaya:
- mengonfirmasi penerimaan laporan dalam **3 hari kerja**,
- memberi penilaian awal dalam **7 hari kerja**,
- merilis perbaikan untuk kerentanan kritis secepatnya, lalu mengumumkannya di CHANGELOG dan GitHub Security Advisory setelah pengguna sempat memperbarui.

Terima kasih telah membantu menjaga repositori perpustakaan Indonesia tetap aman.
